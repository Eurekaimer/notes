# 大学物理 2

!!! tldr "课程简介"
    所属大学：南开大学  
    主讲教师：陈璐  
    先修要求：微积分  
    课程难度：⭐⭐⭐  
    预计学时：5h（只要你懂积分基本就挂不掉了，考前看一下物理规律怎么使用就好）  
    给分情况：30%的平时分+70%的期末  
    考试难度：据说和作业以及例题一致，PS：确实非常一致，而且给分非常好，我基本就写了 7-80 分的内容，最后得分是 3.7（老师不知道怎么给的分），我觉得完全仁至义尽，恩情课程！！！  
    修读时间：Spring 26
